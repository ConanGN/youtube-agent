Next.js 最佳实践

项目结构
- 使用 App Router 目录结构
- 将组件放置在 `app` 目录中，用于特定于路由的组件
- 将共享组件放在“components”目录中
- 将实用程序和助手放在“lib”目录中
- 使用小写字母和破折号来表示目录（例如，`components/auth-wizard`）

＃＃ 成分
- 默认使用服务器组件
- 使用“使用客户端”明确标记客户端组件
- 使用 fallback 将客户端组件包装在 Suspense 中
- 对非关键组件使用动态加载
- 实施适当的错误边界
- 将静态内容和接口放在文件末尾

＃＃ 表现
- 优化图片：使用WebP格式、尺寸数据、延迟加载
- 尽量减少使用“useEffect”和“setState”
- 尽可能使用服务器组件 (RSC)
- 对非关键组件使用动态加载
- 实施适当的缓存策略

## 数据获取
- 尽可能使用服务器组件获取数据
- 为数据获取实施适当的错误处理
- 使用适当的缓存策略
- 适当处理加载和错误状态

## 路由
- 使用 App Router 约定
- 为路线实现适当的加载和错误状态
- 适当使用动态路线
- 必要时处理平行路线

## 表单和验证
- 使用 Zod 进行表单验证
- 实施适当的服务器端验证
- 适当处理表单错误
- 在表单提交期间显示加载状态

状态管理
- 最小化客户端状态
- 谨慎使用 React Context
- 尽可能优先选择服务器状态
- 实现适当的加载状态
